# Pointage CFO / CFA – Hôpital (SS1, RDC, R+1, R+2)

Application de pointage room by room : plans interactifs, 13 systèmes CFO/CFA, réserves avec photo, classeur Excel RAF généré sur le téléphone.

- Hébergement : GitHub Pages (ce dépôt).
- Données : Firebase Firestore (connexion Google, comptes autorisés uniquement), conservées sur le téléphone hors connexion et envoyées au retour du réseau.
- Installation Android : ouvrir le site dans Chrome → menu ⋮ → « Ajouter à l'écran d'accueil ».
